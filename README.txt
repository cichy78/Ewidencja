WAŻNE – JAK ZAINSTALOWAĆ OD NOWA:
1. Usuń starą aplikację z telefonu (jeśli była zainstalowana)
2. W Chrome: Ustawienia → Prywatność → Wyczyść dane przeglądania
   (albo otwórz w trybie incognito)
3. Rozpakuj TEN nowy ZIP
4. Otwórz index.html w Chrome
5. Menu → Zainstaluj aplikację

JAK ZMIENIAĆ MIESIĄCE:
• W zakładce Dni – duże strzałki ‹ › obok nazwy miesiąca
• W zakładce Kalendarz – te same strzałki
• Rok – strzałki w górnym pasku

Przetestowane: nawigacja miesięcy działa poprawnie.
